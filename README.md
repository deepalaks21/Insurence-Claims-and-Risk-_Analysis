# Insurance Dashboard – Power BI

## Project Overview

This project is an **Insurance Data Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides an interactive view of insurance policies and claim-related information. It helps analyze **claim amounts, policy counts, claim frequency, and average claim amount** across different customer, vehicle, and policy-related categories.

## Objectives

- Analyze total insurance policies.
- Analyze total claim amount.
- Understand claim frequency.
- Compare average claim amount.
- Analyze claims by car make and car usage.
- Study claim patterns by coverage zone and customer age.
- Analyze the relationship between claims and kids driving.
- Compare claims across different car years.
- Analyze claims based on education and marital status.
- Compare policy distribution by gender.

## Dashboard Analysis

The dashboard includes analysis based on:

- **Car Make**
- **Car Use**
- **Coverage Zone**
- **Age Category**
- **Kids Driving**
- **Car Year**
- **Education**
- **Marital Status**
- **Gender**
